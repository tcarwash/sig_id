## Scope

This change is the first implementation slice, not the full 19-item program.
It addresses the first five Wave A work packages where safely scoped:
reproducible synthetic decoder baseline; live CV partial padding; embedding
color order and index migration; bounded vectorized spectrogram computation;
and automatic decoder-trial audio selection plus false early acceptance.

No active models are replaced. No radio hardware or transmitting is involved.
No running 8013/8014/8015 services are restarted by this change.

export PYTHONPATH=/storage5/dev/sig_id-cw-keying

  --modes cw,rtty,bpsk31,ax25 --snrs=-5,0,10 \

Source manifest: `$R/synthetic-native-baseline.json` (12 fixed-seed cases).
The only ground truth is generated by Signal Lab; *not independently held-out
on-air recordings* and *no CV detector configured for this run*.

The mid-burst 4 s CW cases in this seed do not contain complete ground-truth

benchmark (25.0% live vs 87.1% synthetic recall at IoU 0.5).
A genuine end-to-end on-air benchmark remains follow-on G0 work.

## Implemented and tests

### A2: robust partial-window background estimate

`sigid/cv_detector.py` now estimates passband background RMS from the median
Hann-window spectral-bin power (with exponential median correction) instead
of RMS of the last 0.5 s, which can contain an active carrier. Retains fixed
seed noise padding and observed sample clipping. Test uses 0.24-amplitude
1.3 kHz carrier on 0.004 RMS background: estimator must remain near
background level. This is robust to narrow transmissions, not a full robust
estimator for occupied 3 kHz voice signals; examine multi-signal cases in G0.

### A3: embedding RGB/BGR consistency

`YoloSignalDetector.embed_image` now converts its RGB image to contiguous BGR
just as `detect` already does. `EMBEDDING_PREPROCESSING_VERSION` is
**v3**, and loading v2 indexes now explicitly fails as incompatible.
**Rebuild any existing embedding index** using `sig-id-build-cv-embedding-index`
before using nearest-neighbor retrieval. The CV detector model/image
preprocessing schema is unchanged by this fix.

### A4: modest bounded vectorization

`sigid.spectrum.waterfall_samples` evaluates at most 64 FFT frames per NumPy
batch, preserving row indices, dB values, and allocation bounds.
`sigid.cv_detector.spectrogram_image` replaces 640 row-by-row + 1,024
column-by-column NumPy interpolation calls with vectorized linear
interpolation. Float32 rounding occurs at the same stage as before; golden
pixel parity tests pass for 8/12/48 kHz, including a full 10 s 48 kHz input.

Actual warm-process CPU medians from three iterations; 10 s synthetic
mono WAV-equivalent array, FFT=4096/hop=512, max 640 rows,
`$R/preprocessing-benchmark.json`:

| Rate | Full image old | Full image new | Speedup | FFT stage old | FFT stage new | Speedup |
|---|---:|---:|---:|---:|---:|---:|
| 12 kHz | 80.05 ms | 76.36 ms | 1.05× | 29.28 ms | 24.40 ms | 1.20× |
| 48 kHz | 118.68 ms | 114.00 ms | 1.04× | 59.67 ms | 51.66 ms | 1.16× |

**Do not claim 10–30×**: the outside review predicted, but this local benchmark
did not observe, those speedups. Further work must profile color palette
mapping, image resizing/copying, and YOLO itself.

### A5: stable-tracked audio for automatic decoder trial

`sigid.api._bounded_live_trial_span` selects up to 10 s of observed audio,
expanding detection regions with a 0.5 s context and a 4 s minimum where
available. It clips to the exact current ring window and defers too-early
candidates without using the once-per-track trial. Both CV and heuristic
auto-trials now call it rather than replaying the 2 s classifier feature crop.
Classifier evidence provenance remains tied to that *separate* 2 s crop.

The shared `DecoderTrialRunner` and isolated Fldigi sweep no longer stop
on a single open-squelch byte. Bounded text buffering can accumulate a
plausible text fragment across callback reads, while small/noisy strings
do not end the tested-mode shortlist. Text remains **tentative**, never
automatically verified. Tests exercise an `X` garbage byte followed by
a valid different-mode string, and confirm the trial proceeds.

## Release/compatibility notes

- Active detector image input `PREPROCESSING_VERSION` remains
  `sig-id-live-waterfall-v2`, deliberately. Pixel output parity is tested.
- Embedding version changed `sig-id-cv-region-embedding-v2` to `v3`;
  rebuilding the index is required before using retrieval.
- 10 s live-ring size and model classification thresholds are unchanged.
  A separate 30–60 s replay ring and source-lineage-held-out real benchmark
  are the next architecture tasks.
- CPU/UI savings may be modest; no changes are deployed to active services
  without a restart. Existing current 8014 capture should be saved before
  restarting its process.
- Live auto-trial needs at least 4 seconds of available audio; short startup
  bursts do not consume the automatic trial once-per-track allowance.
- The new isolation and plausible-text checks are **conservative heuristics**.
  They do not establish correct protocol or text identity. AX.25 FCS remains
  the independent standard for checked frame integrity.
